# bankparse web

Next.js 16 (App Router, Cache Components) + Tailwind 4 + shadcn/ui (Base UI) + TanStack Query.

```bash
npm install
npm run dev       # http://localhost:3000, /api/* proxied to API_URL (default http://127.0.0.1:8000)
npm run gen:api   # regenerate src/lib/api-types.ts from the FastAPI OpenAPI schema
```

See the root README to run the whole app.
